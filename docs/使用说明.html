把磁带中的录像保存到电脑

DV 磁带导出 · Windows 64 位 0.2.0 · Panasonic NV-GS28 USB MotionDV

完整解压 DV-Tape-Exporter-Windows-x64-0.2.zip，双击 DV-Tape-Exporter.exe。软件自动检查摄像机连接，先保存原始录像，再生成方便播放的 MP4。不需要安装 Python 或开发工具。

从开始到保存

  1. 摄像机接外接电源，切到磁带回放，菜单中 USB 功能选MotionDV，再连接 USB。PC / 记忆卡模式不能导出磁带。
  2. 等主界面显示已连接。一台可用摄像机会自动选中；发现多台时，使用更多 → 选择摄像机。
  3. 填写磁带名称，确认保存位置；点击更改…可换文件夹。建议使用 NTFS 或 exFAT，每小时预留至少 18 GB。
  4. 需要从头保存时，使用更多 → 倒带到开头。等摄像机确实停止倒带后，点击开始采集。自动播放不支持时，在摄像机上按播放。
  5. 采集时可查看时长和容量。要结束时点击停止并保存，等待软件写完已收到的录像。

软件每五秒自动检查连接，采集和转换期间暂停检查，开始前会再次确认设备。保存位置和保存选项会记住，下次打开继续使用。完成后点击打开已保存的录像可找到保存文件夹。

一小时录像约需一小时采集。预计时长只用于检查保存空间，软件不会按这个估计时间提前停止；采集保护上限为三小时。

停止后生成 MP4

默认停止后自动生成 MP4。转换期间主按钮变为取消转换；点击后停止转换，原始 DV 仍然保留；未完成的 MP4 不能作为最终结果。也可在更多 → 保存选项…中关闭自动转换。

第一次转换前，使用更多 → 下载播放文件组件。组件来自 FFmpeg 官方下载页列出的 gyan.dev 构建站，核对 SHA-256 后解压。采集原始录像不需要联网；缺少组件时先保存 DV，之后使用更多 → 把已有录像转换为 MP4…。

手动准备组件时，把 Windows FFmpeg 7 或更新版本的完整目录放到软件的 tools 文件夹，保留许可证，并确保 ffmpeg.exe 与 ffprobe.exe 在同一子文件夹。0.2 保留 0.1.1 的 FFmpeg 9 兼容修复。

关闭采集中的窗口会先停止并写完已收到的数据，然后关闭，不会开始新的 MP4 转换。若采集组件异常，超过 30 秒仍无法退出，软件保留部分原始文件并提示检查，这次采集不能认作完整成功。

保存的文件

  • 原始 DV：应保留的原件。包含摄像机送来的声音、元数据、摄像机标错的数据和不足一帧的尾部。
  • MP4：方便播放的 H.264/AAC 副本，PAL 50p / NTSC 59.94p。保留两组立体声位置；没有第二组时对应区间为静音。无法解释的声音格式也在播放副本中用静音并记录，原始声音字节保留在 DV 中。
  • 保存记录：采集结果、原始 SHA-256、格式检查、转换日志和播放文件整段检查结果。

默认保留全部完整 DV 帧。启用末尾占位处理后，只有结构完整、视频字节全 FF、没有声音源信息、声音字节始终相同，且持续至少五秒的末尾占位会被排除。普通静止画面和真实声音场景不会因此删除；原始 DV 始终不裁剪。

文件检查通过不等于源带没有花屏，也不等于物理卷尾已经确认。 普通停止、断线、保护上限和手动停止都不代表物理 END。默认系统连接的 USB 丢包计数为“未知”，不会写成零。人工确认不会改写后端停止原因。

从 0.1.1 升级

先关闭旧程序，将 0.2 小升级包的文件和文件夹复制到原软件目录并覆盖。主要更新 DV-Tape-Exporter.exe、DV-Tape-Exporter.dll 和 DV-Tape-Exporter.deps.json，同时更新说明和源码。原运行时、采集后端和播放组件继续使用，不用重新下载组件或重新采集。

若完整包解压到了新目录，可将旧目录的 tools 一并复制。已下载到当前 Windows 用户缓存的组件仍会自动识别。重新转换已有 DV 时，若之前失败留下同名 MP4，请选新名称。

没有检测到摄像机

检查磁带回放 / MotionDV 模式、电源、USB 线，关闭其他占用摄像机的软件，再重新连接。默认使用 Windows 系统摄像机连接，软件不会自动安装或替换驱动。

高级兼容说明：默认系统连接仍不可用时

Windows 原生 UVC 驱动可以支持 DV，但具体 DirectShow 枚举和 Sample Grabber 组件需要按实际电脑检查。没有枚举到摄像机不能单独证明必须更换驱动。

软件包中的 libusb 后端仅作高级兼容备用，不在日常主流程中自动启用。此方式需要摄像机实际视频功能使用 WinUSB。先在设备管理器按连接查看设备，确认该功能的硬件 ID。NV-GS28 MotionDV 目标为 VID_04DA&PID_231A；记忆卡 / 存储模式的 PID_2316不是目标。

控制和流接口可能由 Windows 合并为一个视频功能，不能预先写死 MI_01。仅在确认实际 VID_04DA&PID_231A&MI_XX属于视频功能后，才考虑使用 Zadig 官方工具配置该功能的 WinUSB；先记录原驱动名称和提供商。不能选择 USB Composite 父设备、记忆卡 / 存储接口或其他设备。软件不会自动执行驱动配置。

如果曾在旧版为视频功能配置 WinUSB，需恢复系统摄像机驱动后再尝试默认连接。恢复时，在设备管理器选择同一视频功能，更新驱动 → 浏览我的电脑 → 让我从可用驱动列表选取原系统摄像机驱动。具体选项以这台电脑实际显示为准。重新连接后再使用默认系统连接。

高级后端只有连续读到两次明确物理 END 状态才报告后端卷尾确认。默认系统连接或普通停止不能提供这个证明。技术接口和构建方式见源码目录中的 src/BUILD.md。

验证范围与许可

0.2 完成 Windows x64 构建和离线回归，尚未进行新版 Windows 界面和摄像机连接的实机复测。首次用新版可先采集约 30 秒，核对画面、声音、停止和保存记录，再采整卷。

离线回归和 FFmpeg 9.0.2 短 DV 检查覆盖原始数据保存、中文及空格路径、双音轨、取消、拒绝覆盖和播放文件解码。这些检查不能代替摄像机实测或物理卷尾确认。
